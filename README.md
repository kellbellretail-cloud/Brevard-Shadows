# Brevard Shadow Atlas

A responsive React/Vite starter for a Space Coast exploration guide. It includes a searchable, category-filtered waypoint directory and map-search links. The current waypoint set is illustrative starter content, not an authoritative or exhaustive directory.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`; preview it with `npm run preview`.

## Before publishing

- Verify each listing, location, accessibility details, hours, fees, and operating conditions with official sources.
- Replace illustrative text and links with approved content and add attribution where needed.
- Configure the hosting provider to build with `npm run build` and serve the generated `dist/` directory.

No API key or backend is required for this starter. Map links open a Google Maps search in a new tab.
